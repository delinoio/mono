The one-time secret dialogs (enrollment token, API key and invitation link) now open with the focus on "Copy" and not on "Done". Pressing Enter or Space right after the dialog opens copies the secret and keeps the dialog open, so a keyboard user no longer closes it before the secret is copied. One Tab moves to "Done"; "Done", Escape and a click outside still close the dialog. The order of the buttons does not change.
