# delidev

DeliDev desktop and mobile app. Desktop builds run on the Chromium Embedded Framework (CEF); Android and iOS builds use the system webview.

```sh
pnpm --filter delidev tauri dev
pnpm --filter delidev tauri build
pnpm --filter delidev tauri android init
pnpm --filter delidev tauri ios init
```
